# 1. Inicio

```
Vamos a empezar siguiendo un guión "estándar"
y a medida que avancemos lo personalizaremos
según las necesidades que vayan surgiendo.
```

## Agenda "clásica"

1. **Requisitos previos**: Instalación del software en la máquina local.
    * Instalación de Ruby
    * Editor. Por ejemplo: VS Codium
    * Cuenta de GitHub para colaborar en un mismo repo.
2. **Hola mundo**: 
    * Usar el editor.
    * Ficheros de texto para el código fuente.
    * Comentarios con `#`.
    * Imprimir mensajes con `puts` (o `print`)
    * Cadenas de texto o Strings.
    * Ejecutar el programa.
3. **Variables**:
    * Variablles de String, Integer, Float.
    * Entrada de datos con `gets`.
    * Entrada de datos con n`ARGV`.
    * Gema `pastel`.
4. **Condicionales**:
    * Estructura secuencial.
    * Estructura condicional.
    * Ámbito de la variable. Bloques.
5. **Vectores, listas, Arrays**:
    * Definición y uso.
    * `irb`
6. **Tareas repetitivas**:
    * Bucles.
    * Iteradores.
    * Estructura repetitiva.
7. **Analizar un problema**:
    * Aanalizar y descomponer.
    * Estructura: secuencial, condicional y bucle
