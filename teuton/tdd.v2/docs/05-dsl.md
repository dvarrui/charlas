
## 5. DSL

Definir DSL:

* **lenguaje diseñado específicamente para resolver problemas en un dominio o área de conocimiento particular**.

Tipos

1. DSL Interno (Embebido)
    * Es un lenguaje que vive dentro de otro lenguaje "anfitrión".
    * Utiliza la sintaxis del lenguaje base pero la adapta para que parezca una herramienta especializada.
    * Ejemplo: Ruby
2. DSL Externo
    * Es un lenguaje que tiene su propia gramática, parser, etc. y no depende de otro lenguaje.
    * Se suele procesar para convertirlo en código ejecutable o para realizar una acción directa.
    * Ejemplo: SQL, matemáticas (álgebra).
    * Se necesita un compilador o intérprete.
